Welcome

Welcome to the editable-list library documentation.

Note: Documentation for the editable-list custom element has not been completed.

The <editable-list> element is meant to allow users to remove arbitrary dom elements in a simple-to-define scope.

It also provides conveniences for editing and adding new elements, without actually implementing functionality to achieve that.

The element is intended to provide a visual component as well as a simple API for maintaining user-editable lists.

Items can be added directly to the list, as well as appended or removed via javascript. The element provides events and parts for list manipulation

Use the Documents menu to navigate to a specific feature's documentation.

Documentation Versioning

Documentation's versioning reflects the latest released build version at the time the documentation was published. It may not reflect the latest version of the library, but all documents should still apply to it.
